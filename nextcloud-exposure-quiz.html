FAQ

How many Nextcloud servers are exposed to CVE-2026-110447?

Censys reported on October 16, 2026 that it detects 19,454 hosts and 103,350 web properties with the vulnerable Collabora built-in CODE Server app installed. Only servers running richdocumentscode below 26.4.303 are actually exploitable.

Am I safe if my Nextcloud isn't internet-facing?

An internal-only server is much harder to reach, but the flaw needs no authentication — anyone who can reach the server's proxy.php endpoint can exploit it. VPN-only or LAN-only deployments are lower risk, not zero risk.

I removed the Collabora app in October — am I in the clear?

Removing the app closes the hole going forward, but if a vulnerable version was installed any time in September–October 2026, you should still hunt for planted web shells (shx*.php / shrf*.php patterns) and review access logs from September 10 onward. Patching or removing never deletes shells.

Is Nextcloud safe?

Nextcloud itself remains safe to use when kept updated — the October 2026 incident was a critical flaw (CVE-2026-110447) in one optional app, the built-in Collabora CODE server, not in Nextcloud core. Stay on a supported release, apply maintenance updates promptly, and remove apps you do not use.

How do I check if my Nextcloud is vulnerable?

Check whether the ‘Collabora Online – Built-in CODE Server’ app (richdocumentscode) is installed and older than 26.4.303 — via Admin > Apps or ‘occ app:list’. If the app was present at any point in September–October 2026, assume exposure and hunt for web shells even after patching.

What should I do if my Nextcloud was hacked?

Take the server offline, restore from a clean backup or rebuild it, and rotate every credential the server touched. Hunt for leftover PHP web shells — patching CVE-2026-110447 does not remove shells attackers already planted — then update the Collabora app to 26.4.303+ or remove it.
