Three honest caveats (from their own docs)

1. Cursor automatic checkpoint capture isn't shipped

The site is explicit: Cursor can retrieve checkpoints over MCP, but native Cursor automatic capture is "not shipped or validated." The Cursor→Claude handoff works through the MCP retrieval path, not magic.

2. Hook records don't include reasoning

Observed hook records never include chat transcripts, reasoning, or inferred next steps. If the next agent needs task instructions, use explicit checkpoints — don't assume the checkpoint contains the thinking.

3. Always verify before trusting a checkpoint

A checkpoint is only as good as the state it points at. The Git-aware verification exists because branches move. Run it; a checkpoint from a merged branch is a trap.
