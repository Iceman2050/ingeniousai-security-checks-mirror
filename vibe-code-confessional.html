FAQ

Can AI coding assistants leak secrets into production code?

Yes. GitGuardian's State of Secrets Sprawl research found 6.4% of repositories with Copilot enabled leaked at least one secret — 40% above the public baseline. Common paths: hard-coded credentials the assistant suggested, secrets pasted into prompts, and credentials committed alongside AI-generated config files.

What are the most common AI coding assistant mistakes?

Accepting suggestions without reading them; shipping code with missing input sanitization (the most common AI-code flaw in academic testing); hard-coded credentials; service-role keys dropped into client code; and vague prompts that produce subtly wrong code.

Is AI-generated code safe to ship without a review?

No. Academic audits find roughly 15–25% of AI-generated code samples contain security vulnerabilities. Treat every AI suggestion as a first draft: read it fully, run static analysis and secrets scanning, and require human review for anything security-sensitive before it reaches production.

How do I stop my AI coding assistant from shipping secrets?

Keep secrets out of prompts, use a secrets manager, add pre-commit secrets scanning, review every AI-generated diff before merging, and restrict the assistant's file access so it cannot read .env files or credential stores.
