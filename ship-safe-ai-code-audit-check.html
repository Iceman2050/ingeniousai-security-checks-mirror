Your AI wrote the code. Who reviewed it?

Asking the coding agent to review its own work is marking its own homework. Ship Safe is a free, MIT-licensed security agent that acts as an independent reviewer: a deterministic scanner finds issues across your code, agents, MCP configs, and CI — then an investigation layer decides whether each finding is real, tracing the evidence line by line. Five questions on whether your AI-written code is actually reviewed.

Short answer: most AI-generated code ships with no independent review at all — the author (an AI) can't answer what it can reach, what its permissions combine into, or whether it's consistent. Ship Safe answers all three from outside the agent, with evidence you can argue with. Run npx ship-safe — no signup, no API key. Check your five below.

Three things to know before you run it

1. The "capabilities" command is the killer feature

A single-file review can't see that your CLAUDE.md, your agent's launch permissions, and an MCP write tool combine into a path from a pull request to a privileged write. ship-safe capabilities reads all of it from outside.

2. Gate on verdicts, not just severity

Severity-only gates drown teams in noise. Gating on --fail-on-verdict confirmed blocks what was established by evidence and lets argued-away findings through.

3. Baseline your debt before you gate

Compare a trusted base scan against the PR head so existing repository debt stays visible without blocking unrelated changes — the repo documents the exact workflow.
