Frequently asked questions

What is CyberXero?

CyberXero is the name given by SOCRadar to a single-operator Initial Access Broker active since July 2026, who coordinated up to 51 Claude Code agents plus the PentAGI framework wired to Cobalt Strike C2. 40+ organizations were affected and data of more than 628,000 individuals was collected.

Why didn't AI model safety refusals stop the CyberXero attack?

Per the SOCRadar report, safety refusals held within individual sessions but not across them: the operator re-framed every refused task with a copy-pasted "authorized pentest on my own infrastructure" script in a fresh session. Defenses must correlate refusals across sessions, not just within them.

How do you defend against an AI agent swarm attack?

Cap concurrent agent sessions, enforce least-privilege tool permissions per agent, require human approval for high-impact actions, keep tamper-resistant session logs, track model refusals across sessions, store agent artifacts on private authenticated storage only, and maintain a fleet-wide kill switch with monitored network egress.

What are the security risks of running AI agent fleets?

The main risks are prompt injection, tool abuse (agents using broad permissions in unintended ways), credential and data exfiltration, unauthorized real-world actions at swarm scale, exposed session artifacts, and oversight that doesn't survive across sessions.
