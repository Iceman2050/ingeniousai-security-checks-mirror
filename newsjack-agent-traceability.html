The 5-point self-check

1

Can you name every tool your agent called this week? Pick any agent and list every tool invocation — function name, arguments, timestamp. Not a guess: the record.

Fail: you can name the tools the agent has access to, not which ones it actually called.
Pass: a complete per-agent tool-call record, queryable by date.
2

Can you trace one data flow end to end? Take a sensitive input — a customer record, a secret — and trace every step where your agent touched it: retrieved, transformed, sent where?

Fail: the trail goes cold after the first tool call.
Pass: full lineage: input → transformations → destinations.
3

Do your traces follow a standard? OpenTelemetry is now the lingua franca — Anthropic exports OTel spans. Ad-hoc JSON blobs in a vendor-locked format aren't interoperable evidence.

Fail: traces in a proprietary format nobody else can read.
Pass: OTel-compatible spans, exportable and portable.
4

Can you reconstruct a session after the fact? Take an agent session from two weeks ago. Can you replay exactly what happened, in order, with outcomes?

Fail: retention expired, or sessions are unreconstructable.
Pass: ordered, replayable session history on demand.
5

Would the trace convince a skeptic? If a regulator, a customer, or your own security team challenged one trace, could you verify its integrity — or is it your word against theirs?

Fail: unverifiable traces; trust me, not proof.
Pass: tamper-evident traces a third party can verify.

If you failed any check, do this now

  • Instrument every agent — record every tool call, argument, and outcome from day one.
  • Emit standard traces — OTel-compatible spans, so your evidence works everywhere.
  • Keep session history — replayable records, retained long enough to matter.
  • Make traces verifiable — hash-chain them so integrity is provable, not promised.
