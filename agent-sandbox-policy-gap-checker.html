What is an AI agent sandbox, exactly?

Direct answer: An AI agent sandbox combines OS-level isolation with a policy engine that approves or denies every agent action — shell commands, code runs, network requests, tool calls. AWS's Strands Box (October 2026) adds history-aware Dogwood policies, but a sandbox is only as strong as its policy: gaps like self-editing rules or open egress defeat it.

Frequently asked questions

What is AWS Strands Box?

Strands Box is an open-source AI agent sandbox from AWS's Strands Agents team, released in developer preview on October 7, 2026 under the Apache 2.0 license. It pairs OS-level isolation (macOS Seatbelt) with a policy engine, is deny-by-default, and currently supports Macs with Apple silicon only, with Linux and other platforms planned.

What is the Dogwood policy language?

Dogwood is AWS's open-source policy language (building on its Cedar language) with a Local Engine that evaluates each requested action against the agent's recorded history. Example from AWS: an incident agent may post to Slack, but no more than three times every 10 minutes — the box enforces the limit from history, not from the agent's memory.

Can an agent inside the sandbox edit its own policy?

That is the gap this checker tests. In Strands Box the policy lives in box.toml, enforced at the syscall level by Seatbelt. If the agent can write to that file or its config directory, the sandbox ends up answering to the agent. AWS's own caveat is that policies "may be difficult to understand, and difficult to write" — misconfigurations are easy.

Is a deny-by-default sandbox enough for AI agents?

No. Deny-by-default is the floor, not the ceiling. You also need history-aware rules (judge sequences, not single actions), egress allowlists, credential injection at the gateway, an MCP/tool broker that reviews every call, and self-modification protection — the five dimensions this checker scores.

Does this checker replace a security audit?

No. This is a heuristic self-assessment: your answers plus a keyword scan of pasted policy text, scored against five known gap areas. It cannot parse real Dogwood/Cedar semantics, cannot see your runtime, and is not legal or security advice. Use it to find blind spots, then verify with a proper review.
