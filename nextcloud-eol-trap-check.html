CVE-2026-110447 — THE EOL TRAP

The EOL trap

Here's the nasty part nobody put on a poster: Nextcloud 29 and older are end of life — and the app store still serves them the vulnerable Collabora app. The fixed app version requires Nextcloud 30+. So if you're on 29, there is no safe version of the app you can install. Type your version to see where you stand.

Version check

Find yours with: sudo -u www-data php occ --version — then enter it below (e.g. 29.0.5, 31.0.2).


Why the trap exists

  • Nextcloud 29 and older are end of life. No more security updates, full stop.
  • The app store still serves these EOL versions an affected richdocumentscode — so a routine "update all apps" can install the vulnerable code on a server that can never be patched for it.
  • The fixed app (26.4.303) requires Nextcloud 30 or later. There is no patched build for 29.
  • Your two honest exits: upgrade Nextcloud to a supported release, or remove the built-in CODE Server app entirely. Disabling it does not protect you either way.

Sources: The Hacker News · CyberPress · Censys · help.nextcloud.com maintenance post
