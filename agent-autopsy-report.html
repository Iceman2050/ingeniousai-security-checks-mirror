AGENT INCIDENT CORONER

Agent Autopsy Report

Every agent failure leaves a corpse. We perform the autopsy: the kill chain, the exact guardrail that would have stopped it, and the defense that covers it.

Evidence standard. Each incident below is either a publicly documented real incident with its source named, or is explicitly labeled as a composite of public research. We never invent incidents. Free-text reports get a generic template — generated from your description, not from evidence.

How to read an autopsy

Kill chain — the numbered sequence of steps the attacker (or the runaway agent) took, in order. Every step is a place the attack could have been broken.

Guardrail — the single exact control that breaks the chain. Not a product pitch: a control you can implement regardless of vendor.

Platform coverage — which of our defenses covers each link, so you know where it would have been caught. Covered platforms are marked; uncovered ones are dimmed.

Educational tool. Incident data is drawn from the public record as cited; it is not legal or forensic advice. If you run agents with tool access, assume they are in scope for every pattern above.
