FAQ

What happened in the ConnectWise Cloud Backup breach?

Attackers used a stolen ConnectWise Cloud Backup credential to sign into 173 Microsoft 365 tenants without MFA. The targeting focused on policy, national-security, trade, and critical-minerals organizations, and a second wave was observed on October 15.

Why didn't MFA stop this attack?

The attackers abused a trusted third-party app identity — ConnectWise's Cloud Backup service principal — so the sign-ins looked legitimate to Microsoft Entra ID and no MFA challenge was triggered.

What has ConnectWise done about it?

On October 17, 2026 ConnectWise disabled 7 app identities, suspended the Cloud Backup service, and revoked certificates — while warning that previously issued tokens may remain valid, so tenants must hunt for them.
