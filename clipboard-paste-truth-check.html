What Is Phishing? Watch a ‘Harmless’ Paste Betray Itself

What is phishing? Most people picture a fake email asking for a password. But in October 2026, attackers skipped email entirely: a fake Claude installer site displayed a harmless-looking install command, while its Copy button placed a different command on visitors' clipboards. Phishing is a deception attack that tricks you into running the attacker's code or handing over credentials — and 4 in 5 (80%) of these ClickFix-style attacks now arrive through search results, per the campaign coverage. This page replays the trick on you, safely, then shows the byte-level truth hiding in your clipboard.

Direct answer: What you see is not always what you paste. A single invisible character — a zero-width space, a right-to-left override, an ANSI escape — can make a harmless-looking command carry a hidden payload. The only reliable check is byte-level: compare the visible text against the actual bytes before you run anything you copied.

What is phishing via clipboard deception?

Clipboard-deception phishing shows you one command and copies another. The visible text — npm install claude-desktop — looks safe, but the clipboard bytes can hide a second command after a zero-width character or a direction override. Your terminal runs the bytes, not the pixels. Inspecting those bytes before pasting is the difference between installing software and installing malware.

Frequently asked questions

What is phishing, exactly?

Phishing is a deception attack that tricks you into acting against your own interests — running an attacker's command, entering credentials on a fake page, or sending money to a scammer. Classic phishing arrives by email or text, but the October 2026 fake-installer campaign showed it can hide in your clipboard: the command you see and the bytes you paste are different things. Always verify before you act.

How did the fake Claude installer attack work?

In October 2026, fake Claude installer sites promoted through search ads showed visitors a harmless-looking install command. Their Copy button placed a different command on the clipboard — one that fetched and ran a remote payload. Victims pasted and ran bytes they never saw. Campaign coverage reports 4 in 5 (80%) of these ClickFix-style attacks now arrive via search rather than email.

What is a zero-width character, and why does it matter?

A zero-width character (like U+200B) is a real byte that renders as nothing on screen. Attackers hide commands after one: you see “npm install widget” but the clipboard holds the visible text plus a hidden second command. Your terminal executes the bytes, not the pixels. A byte inspector makes the hidden part visible before you paste.

Can I check my clipboard before pasting?

Yes. The byte inspector on this page analyzes any text you paste into it — install commands, contract clauses, wallet addresses — and reports invisible unicode, ANSI escapes, direction overrides, suspicious launchers, and lookalike URLs with PASS, WARN, or BLOCK verdicts. Everything runs in your browser; nothing is uploaded. The open-source paste-truth-guard tool does the same from your terminal.

Does a clean scan mean a command is safe to run?

No. A clean scan means no known deception markers were found — not that the command is safe. A perfectly visible malicious command still passes, because the tool checks whether what you see matches what you would paste, not whether the visible text itself is wise to run. Treat a clean scan as one check passed, not as permission.
