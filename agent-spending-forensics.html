AI API spending — quick answers

How do I find out what's burning my AI API budget?

Start with your invoice or usage summary: total input tokens, total output tokens, total cost, and the billing period. This tool splits your spend into input vs output, estimates cache-hit tokens from the cache percentage you enter, and flags the top three likely waste patterns — all from your own numbers.

Why is my LLM output bill higher than my input bill?

Output tokens are typically priced higher than input tokens by most providers, and agents that 'think out loud' or re-emit long contexts generate far more of them. An output-to-input ratio above roughly 2:1 is a common sign your agent is over-generating — that is the first flag this tool checks.

What is prompt caching and how much does it save?

Prompt caching lets providers reuse the processing of repeated prompt prefixes — like your system prompt — instead of charging you the full input price every call. This tool estimates your cache-hit tokens from the cache percentage you enter; if that percentage is under 10%, the lack of caching is flagged as your first cost fix.

How can I cut my AI agent's API costs?

The usual wins are: enable prompt caching, trim oversized context windows, batch calls instead of one-at-a-time requests, add retry backoff so failures don't burn tokens twice, and cap output length. Fix the waste flags this tool reports first — they are the highest-leverage items.

Is this an official audit of my provider invoice?

No. Every number on this page is an estimate derived from the numbers you type in. We never invent provider pricing — your own invoice figures are the only source of truth, and this tool is a guidance aid, not an official billing audit.
