AI API spending — quick answers — FAQ

What is the biggest factor affecting LLM API costs?

Token count drives the bill — and output tokens are typically priced several times higher than input tokens by most providers. (Estimate.) An AI API cost calculator shows whether input or output dominates your spend; agents that "think out loud" usually show a heavy output skew, which is the first waste flag this tool checks.

How do I reduce my LLM API bill?

The usual wins: enable prompt caching, use the cheapest model that passes your quality bar, trim oversized context windows, cap output length, add retry backoff so failures don't burn tokens twice, and batch calls instead of one-at-a-time requests. Fix the waste flags this tool reports first — they are the highest-leverage items.

What is prompt caching and how much does it save?

Prompt caching lets providers reuse the processing of repeated prompt prefixes — like your system prompt — at a discounted input rate instead of charging full price every call. This tool estimates your cache-hit tokens from the cache percentage you enter; if that percentage is under 10%, the missing cache is flagged as your first cost fix. (Estimate.)

Should I use the batch API to cut AI API costs?

If the workload isn't time-sensitive, yes. Providers' batch queues are typically advertised at roughly half the standard rate, with results delivered hours later instead of seconds — good for summarization, enrichment, and evaluation runs; bad for real-time chat.
