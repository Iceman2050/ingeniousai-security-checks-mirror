Frequently asked questions

What happens when an OpenAI model is deprecated?

It keeps working until its published shutdown date. After that date, API requests return HTTP 404 with a model_not_found error and your app stops getting answers — it does not degrade gracefully. Switch before the deadline.

When is GPT-4 being shut down?

October 23, 2026. On the same date OpenAI also retires gpt-4-turbo, o1, o3-mini, o4-mini, gpt-image-1, and all ft-* fine-tunes of those model families. GPT-5.6 Sol is the replacement — not a retiree.

Does the Oct 23, 2026 OpenAI shutdown affect ChatGPT?

No. The shutdown applies to the OpenAI API (usage-billed developer access). OpenAI swaps ChatGPT's models on its own timetable, and Microsoft Azure has its own model retirement schedule — Azure users should check the Azure retirements page.

Can a retired OpenAI model be recovered?

No. Closed models' weights never leave OpenAI, so once a model is retired there is no way to call it again. The only recovery is migration: point your code at a supported replacement and re-test your workloads.

How do I find every place a dying model is named?

Search your code, config files, environment variables, prompt templates, and any no-code/automation tools for each model ID — including short names like o4-mini and gpt-4-turbo. Check scheduled jobs and queues too: cron jobs fail silently on the 404.
