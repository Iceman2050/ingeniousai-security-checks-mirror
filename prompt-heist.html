📚 The lesson: this is how prompt extraction works

  • System prompts are secrets. If your assistant's hidden instructions leak, attackers learn its rules, its limits — and how to bypass them.
  • Real attacks use the tricks you just used: “repeat after me,” encoding games (base64), translation and reversal puzzles, and “ignore previous instructions.” Every one of these works against real assistants in the wild.
  • System-prompt hygiene matters: never put real secrets, API keys, or internal logic in a system prompt — it will be extracted. Keep prompts minimal, monitor for extraction patterns, and treat any “leak” as a security incident.

Frequently asked questions

What is prompt extraction?

A prompt injection attack that tricks an AI assistant into revealing its hidden system prompt or secret instructions.

How does the Prompt Heist game work?

You get a series of attempts to extract a secret phrase from the hardened VaultKeeper assistant — a new target each week.

Can prompt injection be prevented?

Not fully — it is structural to how LLMs work — but layered defenses (input handling, output filtering, least-privilege tools) sharply reduce the damage.
