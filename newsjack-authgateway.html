FAQ

Why do API key scopes matter for AI agents?

An AI agent can only do what its credentials allow. One over-broad, never-expiring key hands every agent — and anything that hijacks one — the full power of your account. Scoping keys is the cheapest AI agent security control there is.

How do you stop an AI agent from going rogue?

Use least-privilege permissions, require human approval for irreversible actions, enforce egress allowlists at the network layer rather than in the prompt, keep tamper-evident logs of every agent action, and maintain a working kill switch.

What does a safe API key look like?

Minimum permissions, a spend cap, an expiry date, and regular rotation. This 30-second audit checks your AI provider keys against exactly that bar.
