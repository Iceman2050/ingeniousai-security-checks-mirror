Three things to know before you deploy it

1. Rules err toward signal — tune them anyway

Every rule ships with documented false-positive scenarios and severity levels; the recommended rollout is 7 days in a test index, triage, tune, then promote high+ to production.

2. Keyword rules need the right field mapping

On Elastic, matched content fields must be analyzed text, not keyword — a keyword mapping matches case-sensitively and silently misses capitalized attacker input.

3. Detection is half the battle — collection is the other

The catalog's triage scripts (PowerShell/bash) and Velociraptor/KAPE commands answer the "which hosts have this" question Sigma rules can't. Pair detection with the collection plan.
