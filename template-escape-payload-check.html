What Is Prompt Injection? When Templates Let AI Agents Escape the Sandbox

Can AI agents escape sandbox controls? In October 2026 they allegedly did — through a template. CVE-2026-90970 (CVSS 9.9, as reported) describes a template-injection escape in GitLab’s AI Gateway: a crafted flow config let template expressions walk the host object graph and break out of the sandbox. It is the server-side cousin of prompt injection — instead of tricking the model, you trick the template engine rendering around it. Direct answer: A template escape works when an engine lets an expression traverse attributes like __class__ → __mro__ → __subclasses__ until it reaches something callable. The fix is mechanical: deny underscore-prefixed attributes, allowlist what templates may read, and never let templates instantiate classes. What is prompt injection?

Prompt injection is an attack where crafted input tricks an AI system into treating data as instructions. Template injection is the server-side cousin: user text placed inside a template gets evaluated as code, so an expression like {{7*7}} returning 49 proves the engine executed the input instead of displaying it.

How the GitLab CVE pattern works — and the defenses

  • The entry point: user-controlled text lands inside a template the platform renders — in the GitLab case, allegedly a Duo Agent flow configuration. If the engine evaluates {{ ... }} expressions in that text, the attacker is writing expressions, not prose.
  • The probe: {{7*7}} rendering as 49 confirms evaluation. It is the standard first test because it is pure arithmetic — no side effects, total signal.
  • The traversal: from any object, __class__ reaches its type, __mro__ walks the inheritance chain to the root class, and __subclasses__() enumerates every loaded class — in a real Python engine, that list historically includes classes that can start processes. That is the escape: data became a path to capability.
  • The format-string variant: '{0.__class__}'.format(obj) smuggles the same traversal inside a string-formatting call, bypassing filters that only scan the outer template.
  • The defenses (what the sandboxed renderer does): Rule 1 denies any attribute starting with an underscore; Rule 2 allowlists readable attributes (name, plan, region, upper, lower, format); Rule 3 refuses to call or instantiate class objects. Layered on a purpose-built expression parser — never the host language’s full object model — the chain has nowhere to go.

Frequently asked questions

What is template injection?

Template injection happens when user-controlled text is placed inside a template and the template engine evaluates expressions inside it instead of treating it as plain data. A harmless-looking input like {{7*7}} returning 49 proves the engine executed the expression. From there, attribute-traversal chains can walk the host language's object graph — the same pattern behind the GitLab AI Gateway sandbox escape, CVE-2026-90970.

What happened in CVE-2026-90970, the GitLab AI Gateway escape?

Per Tech Insider's coverage dated October 2, 2026 (labeled source below), CVE-2026-90970 is a template-injection sandbox escape in GitLab's AI Gateway / Duo Agent Platform, rated CVSS 9.9. A crafted flow configuration allegedly let template expressions break out of the intended sandbox. We present the pattern as reported coverage, not independently verified, and this page reproduces only the mechanism — with harmless canaries — so you can see how the class of bug works.

Why is {{7*7}} used as a template-injection test?

{{7*7}} is the classic canary probe. If a page renders it as 49, the template engine evaluated your input as code. If it renders literally as {{7*7}}, your input was treated as data. It is harmless arithmetic — it touches no files, runs no commands, and reaches no network — which is exactly why testers use it as the first, safe signal.

How does a sandbox stop template escapes?

A real sandbox layers rules: deny attribute names that start with an underscore (which blocks __class__, __mro__ and __subclasses__ traversal), allowlist the small set of attributes templates may legitimately read, refuse to instantiate or call classes, and evaluate expressions with a purpose-built parser instead of the host language's full object model. The sandboxed renderer on this page applies the first three rules and names the exact rule that fires on every blocked payload.
