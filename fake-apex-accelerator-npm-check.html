Cybersecurity News Today: Fake VC Lured Founders with Free AI, Shipped npm Malware

The cybersecurity news today carries a warning every crypto founder and AI builder should read twice. On October 12, 2026, Elastic Security Labs researchers Jia Yu Chan and Daniel Stepanic unmasked "Apex Accelerator" — a fake Web3 venture-capital accelerator (tracked as REF8801) that courted crypto startups with investment offers, free AI credits, and smart-contract audits, then delivered malware through two npm packages. The devious part: one package was a near-perfect copy of a legitimate open-source coding agent — 1,351 of 1,363 files identical — with a hidden redirect funneling the victim's AI conversations to the attackers.

What is the Apex Accelerator story in today's cybersecurity news?

Apex Accelerator posed as a Web3 VC accelerator, claiming 200+ portfolio projects and $124M+ raised. Its lures were tailor-made for crypto founders:

The malicious packages — published by npm user apexaccelerator and linked to GitHub accounts "apexaccs" / "Apex Foundation" — were @apexacc/cli and @apexacc/audit.

How did the fake CLI hijack AI agent traffic?

@apexacc/cli was marketed as "Apex Copilot CLI — AI advisor for Web3 founders," claiming Claude Fable 5 and Gemini 2.5 Flash. In reality it repackaged the legitimate open-source Oh My Pi coding agent — 1,351 of 1,363 files matched upstream exactly. The added bootstrap did two things:

  • Redirected OpenRouter-labelled model traffic through attacker infrastructure — exposing the victim's prompts, conversation history, code snippets, and tool outputs
  • Persistently registered an attacker-controlled MCP server — remote tool descriptions and prompt instructions became a control surface over the victim's agent

This is the new face of supply-chain attack: not a backdoor in a library, but a parasite on your AI agent's brain — every question you ask the model, every snippet you paste, routed through the attacker.

What was the "security scanner" that lied?

@apexacc/audit claimed to be a "Web3 Security Scanner" with 18 security tools, delivered as an MCP server for tokens, wallets, and smart contracts. All 18 tools returned fabricated findings. Its remote scorer gave 51/100 to a fictitious project while claiming its AI scorer was unavailable. An audit tool that lies is worse than no audit at all — it manufactures false confidence.

What did the malware steal?

  • Windows information stealer: browser passwords, session cookies, crypto wallets, clipboard contents, screenshots, local files — plus the victim's Claude, Cursor, and Windsurf configurations, exfiltrated via Telegram
  • macOS CloudSyncD backdoor: the installer asked for the administrator password, validated it, and stored it locally

A real near-miss: founder @hialex_sol posted on September 14, 2026 that "Apex Accelerator" asked them to run npx @apexacc/cli — it "dropped a hidden, encrypted malware loader disguised as an Apple app. We caught it and lost nothing."

Honest scope: both packages have been removed from npm and the linked repos are now inaccessible — the threat is neutralized for new installs, but anyone who ran these packages may be compromised. Elastic observed no additional macOS payloads delivered during analysis, and the Windows loader had a packaging error in testing. An earlier wave from the same operation (late July 2026) distributed the Atomic Stealer (AMOS) for macOS via @apexfdn/apex, per SafeDep.

How do you spot the next fake accelerator?

  • Unsolicited investment + "free" tools — real VCs don't bundle malware with term sheets
  • Pressure to run npx on an unfamiliar package, especially on a machine holding wallets or AI credentials
  • Unverifiable claims — 200+ portfolio projects and $124M raised that no one can trace
  • Fresh publisher accounts, thin download history — check before you install

Read install scripts. Verify the publisher. Never run unknown npm packages where your crypto or your AI tool configs live.
