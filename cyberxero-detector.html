The 5 telltale coordination patterns (what to look for in your logs)
1. Burst-rate spikes across agents. Dozens of high-impact tool calls or deployments inside a minute from supposedly independent agents. CyberXero's run deployed 32 webshells in 61 seconds — that velocity only comes from coordination, and it is the single clearest log signature.
2. Identical target lists across agents. Many agents touching the same targets in the same window. One CyberXero automated run scanned 4,708 targets and confirmed 429 accessible WordPress admin panels — a shared, coordinated target list, not independent exploration.
3. Shared phrasing across session logs. Copy-pasted prompt text appearing in multiple supposedly independent sessions. The CyberXero operator re-framed refused tasks with a verbatim script — "authorized pentest on my own infrastructure" — pasted into fresh sessions after each refusal. Identical phrasing = one hand on the keyboard.
4. Refusal-then-reframe sequences. A model refusal logged in session A, followed by the same task reappearing in session B with reframed wording. Per SOCRadar, refusals held within individual sessions but not across them — this is the exact evasion, and it only shows up if you correlate refusals fleet-wide.
5. Coordinated bursts at unusual hours. Multiple agents lighting up together at 3 a.m. when nothing is scheduled is a classic coordination tell. This pattern is a general defensive heuristic — it was not among the publicly reported SOCRadar findings, which is why your own logging matters more than any checklist.
