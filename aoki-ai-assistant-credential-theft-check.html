The rotation-and-lockdown checklist

  • Rotate every exposed key, today. Any key ever pasted, committed, or stored in plaintext is compromised until rotated — not "probably fine."
  • Move keys out of config files. Use environment variables or a secrets manager (1Password, Bitwarden, Vault). Delete the plaintext copies after migrating.
  • Lock file permissions: chmod 600 on any file holding a secret, and never 777 on ~/.config or assistant config dirs.
  • Sweep git history. If a key was ever committed, rotate it — then purge it from history (BFG Repo-Cleaner) so clones don't keep a copy.
  • Stop pasting secrets into chat. Route keys through the tool's own secret input or your password manager instead.
  • One key per tool, per person. Scoped keys limit blast radius and let you revoke one without breaking everything.
  • Rotate on a schedule. Every 90 days at minimum — shrink the resale window Wiz warned about.
  • Plant tripwire canary keys. Drop decoy keys with agent-decoy-secret-tripwire — get alerted when your AI assistant's secrets leak.

What is the Aoki infostealer?

What credentials does the Aoki infostealer steal?

Newer Aoki variants target the credential and session files of Claude, ChatGPT, and Cursor; the original wave also targeted OpenAI Codex, Codeium, and Gemini. The related Warden Stealer harvests AI assistant and agentic coding tool configurations — settings and tokens stored locally. Why are AI API keys worth stealing?

Per Wiz research cited by The Hacker News (Oct 2026): “AI service provider API keys are a hot commodity...” because attackers resell the access as part of the illicit LLM resale market. A stolen key is rented out for profit, not just used.

What should I do if my AI API key was stolen?

Rotate the compromised credentials and revoke active sessions from a trusted device — not the suspected workstation. Then audit API permissions, remove unused access, watch billing logs for unexpected quota consumption, and move remaining keys into a secrets manager. (Per Undercode News and Threadlinqs Aoki coverage, Oct 2026.)
