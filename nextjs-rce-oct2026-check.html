NEXT.JS OUT-OF-BAND — OCT 14, 2026 — 2× RCE CVSS 9.5

Two unauthenticated RCEs in Next.js — are you patched?

Next.js just shipped an out-of-band security update for two critical unauthenticated remote-code-execution flaws (CVSS 9.5 each) plus a high-severity denial-of-service bug. One RCE hides in React Server Components' use cache; the other in SVG image processing via sharp/librsvg on glibc Linux. No login needed for either. Paste your Next.js version for an instant verdict. Free, no signup.

RCE via use cache

RCE via SVG images
CVE-2026-96889
CVSS 9.5		10.0.0 – 15.5.27

DoS via Server Actions
GHSA-p3m5-59mp-jv5r
High		13.0.0 – 15.5.27
and 16.0.0 – 16.4.0		15.5.28, 16.4.1App Router apps with ≥1 Server Action. Crafted requests burn CPU and block the process. Pages Router apps are not affected by this one.

As of Oct 15: no public reports of exploitation, and two of the advisories were missing from the npm audit feed — npm audit alone may not warn you. Check the version manually.

Patch now — the order matters

  • Upgrade Next.js to 16.4.1 (Active LTS) or 15.5.28 (Maintenance LTS). Upgrading pulls a fixed sharp automatically.
  • Can't upgrade today? For the SVG RCE only: pin sharp ≥ 0.35.5 or block SVG loads in sharp. There is no workaround for the use cache RCE — that one needs the upgrade.
  • Audit your exposure: grep for use cache functions returning typed arrays, check for dangerouslyAllowSVG or next/og usage, inventory your Server Actions.
