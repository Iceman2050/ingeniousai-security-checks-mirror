How the grade works

What does the scanner check?

Hardcoded secrets and API keys, SQL injection patterns, XSS sinks, dangerous functions (eval, exec, shell calls), insecure deserialization, and CI/CD pipeline risks — including malicious workflow injection in the style of the October 2026 GhostAction supply-chain campaign.

How is the score calculated?

Every repo starts at 100. Critical findings subtract 25, high 10, medium 4, low 1. 90+ is an A, 75+ a B, 50+ a C, 25+ a D, below that an F. Test fixtures, docs, and example files are excluded — only shipped code counts.

Is it really free?

Yes. The badge, the scan behind it, and the report page are all free with no signup. It's built by Ingenious AI, the team behind Vibe-Code Audit.

Can the badge improve my project's trust?

That's the point. A visible, independently-computed security grade answers the first question every evaluator asks: "is this safe to depend on?" Link it next to your build-status badge.

Methodology: static analysis of shipped production code (October 2026 scan). Grades reflect the code as scanned; rescan after significant changes. A badge is a signal, not a certification.
